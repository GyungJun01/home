========================================
📝 모델 선택 가이드
========================================

1. 404 에러가 발생하는 경우:
   → claude-3-haiku-20240307 사용 (현재 설정)
   → claude-3-sonnet-20240229 사용
   → 이 두 모델은 가장 범용적으로 접근 가능

2. 더 나은 성능이 필요한 경우:
   → claude-3-opus-20240229 시도
   → claude-3-5-sonnet-20240620 시도 (권한이 있다면)

3. 빠른 응답이 필요한 경우:
   → claude-3-haiku-20240307 (현재 설정)
   → claude-3-5-haiku-20241022 시도 (권한이 있다면)

4. 최신 기능이 필요한 경우:
   → Claude 4 시리즈 시도 (권한이 있다면)
   → 단, 대부분의 일반 API 키는 접근 불가

========================================
🔧 모델 변경 방법
========================================

app.py 파일의 126번 라인을 수정:

# 현재 설정 (권장)
model="claude-3-haiku-20240307"

# 더 나은 성능 원하면
model="claude-3-sonnet-20240229"

# 최고 성능 원하면 (비용 높음)
model="claude-3-opus-20240229"

# 최신 모델 시도 (404 에러 발생 가능)
model="claude-3-5-sonnet-20240620"
model="claude-3-5-sonnet-20241022"

========================================
💡 모델 별칭 사용
========================================

특정 버전 대신 별칭을 사용할 수도 있습니다:

model="claude-3-haiku-latest"    # 최신 Haiku 자동 선택
model="claude-3-sonnet-latest"   # 최신 Sonnet 자동 선택
model="claude-3-opus-latest"     # 최신 Opus 자동 선택

주의: 별칭은 자동으로 최신 버전으로 업데이트되므로,
프로덕션 환경에서는 정확한 버전을 명시하는 것이 좋습니다.

========================================
⚠️ 주의사항
========================================

1. API 키 권한에 따라 접근 가능한 모델이 다릅니다
2. 404 에러 = 모델 접근 권한 없음 또는 모델명 오류
3. 최신 모델일수록 접근 제한이 많을 수 있음
4. 무료 티어는 일부 모델만 사용 가능
5. 모델 이름 오타 주의 (대소문자, 날짜 형식 정확히)
